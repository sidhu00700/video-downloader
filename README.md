# 🎬 MASTER Video Downloader

A modern Flask-based video downloader supporting MP4 and MP3 downloads with 720p and 1080p video quality.

## ✨ Features

- 🎥 MP4 Video Downloads
- 🎵 MP3 Audio Downloads
- ⚡ 720p Video Quality
- 🚀 1080p Video Quality
- 🌙 Dark / Light Mode
- 🔗 YouTube Support
- 🎵 TikTok Support
- 📸 Instagram Support
- 📘 Facebook Support
- 🐦 Twitter / X Support
- 🛠️ FFmpeg Processing
- 📱 Responsive UI
- 🔒 Server-side processing

## 🧰 Tech Stack

- Python
- Flask
- yt-dlp
- FFmpeg
- HTML
- CSS
- JavaScript

## 🚀 Run Locally

```bash
pip install -r requirements.txt
python app.py
